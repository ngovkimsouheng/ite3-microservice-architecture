What is Change Data Capture?
Change Data Capture (CDC) គឺជា Design Pattern មួយដែលប្រើសម្រាប់កំណត់ អត្តសញ្ញាណ (Identify) និងចាប់យក (Capture) រាល់ការផ្លាស់ប្តូរទិន្នន័យនៅក្នុង Database បន្ទាប់មកបញ្ជូនការផ្លាស់ប្តូរទាំងនោះទៅកាន់ Downstream Systems ក្នុងលក្ខណៈ Real-time ឬ Near Real-time។
Types of Change Data Capture (CDC)
Change Data Capture (CDC) មានវិធីសាស្ត្រសំខាន់ៗចំនួន 4 Types :
Log-Based CDC
Trigger-Based CDC
Query-Based CDC (Polling-Based)
Snapshot-Based CDC (Table Comparison)

MERGE INTO cdc_demo.customers AS target
USING customer_updates AS source
ON target.id = source.id

WHEN MATCHED AND source.op = 'd'
THEN DELETE

WHEN MATCHED AND source.op IN ('u', 'c', 'r')
THEN UPDATE SET *

WHEN NOT MATCHED AND source.op IN ('c', 'r')
THEN INSERT *;
Explain MERGE
MERGE INTO: កំណត់ Target Table។
USING: កំណត់ Source Data។
ON: កំណត់ Key សម្រាប់ Match។
WHEN MATCHED: Record មានស្រាប់។
THEN UPDATE: កែប្រែ Record។
THEN DELETE: លុប Record។
WHEN NOT MATCHED: Record មិនទាន់មាន។
THEN INSERT: បញ្ចូល Record ថ្មី។

រៀបរៀងដោយ៖ សន​ សុភីរ៉ាម
raw_df = (spark.readStream.format("kafka")
    .option("kafka.bootstrap.servers", KAFKA_BOOTSTRAP_SERVERS )
    .option("subscribe", KAFKA_TOPIC)
    .option("startingOffsets", "earliest").load())

parsed_cdc_df = (raw_df.selectExpr("CAST(value AS STRING) as json_val")
    .select(from_json(col("json_val"), debezium_schema).alias("data"))
    .select("data.payload.op", "data.payload.before", "data.payload.after", "data.payload.ts_ms")
    .filter(col("op").isNotNull()))

Explain the Code
readStream
ប្រើសម្រាប់ Read Streaming Data។
format("kafka")
ប្រាប់ Spark ថា Source គឺ Kafka។
kafka.bootstrap.servers
កំណត់ Kafka Broker Endpoint។
subscribe
កំណត់ Topic ដែលយើងចង់អាន។
startingOffsets
កំណត់ទីតាំង Offset ដែលចាប់ផ្តើមអាន។
earliest មានន័យថាចាប់ផ្តើមពី Earliest Available Offset នៅពេល Streaming Query ចាប់ផ្តើមថ្មី។
